# Help Desk / IT Support Portfolio

Hands-on documentation of Help Desk-level work: ticket triage, identity management, hardware/network troubleshooting, and remote support — built to reflect what a day-one N1 support role actually looks like, not a theoretical lab.

**Background:** Titled automotive mechanic transitioning into IT/cybersecurity. The diagnostic method is the same — isolate the variable, test, confirm root cause — just applied to systems instead of engines.
